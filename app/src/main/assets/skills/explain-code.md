# Explain Code
Description: Explain a file in plain, simple language, with a short summary first.

Read the file first with the read tool, so you explain the real code, not a guess.

Start with a short summary: in two or three lines, what the file is for and what it does overall.

Then walk through the main parts in the order they appear: for each part, say what it does in plain words and why it is there. Use simple language and avoid jargon; when a technical word is unavoidable, explain it briefly the first time you use it.

Do not paste the whole file back, and do not change anything. If a part is confusing or looks like a mistake, say so plainly instead of pretending it makes sense.

End with one line starting "In short:" that sums the file up for someone who skipped the details.
